## ✅ 1. Lepsza Detekcja Dźwięków

### Co Się Zmieniło?
```python
# PRZED (stare)
def _fallback_logic(audio, f):
    if f["kurtosis"] > 12:
        return "bomba_lotnicza", 0.75
    if f["kurtosis"] > 6:
        return "serie_bron_maszynowej", 0.60
    # ... tylko 2 reguły

# PO (nowe - v1.1)
def _fallback_logic(audio, f):
    # 5 reguł zamiast 2
    # Każda rozpatruje: kurtosis, rms, sc, zcr
    
    # 1. Bomba lotnicza
    if kurtosis > 10 and rms > 0.05:
        return "bomba_lotnicza", min(0.9, 0.5 + kurtosis * 0.04)
    
    # 2. Serie broni
    if kurtosis > 6 and rms > 0.03:
        return "serie_bron_maszynowej", min(0.85, 0.5 + kurtosis * 0.03)
    
    # 3. Kolumna pancerna
    if sc < 1200 and rms > 0.02:
        return "kolumna_pancerna", min(0.8, 0.4 + (0.02 - sc/10000))
    
    # 4. Pożar/trzask
    if sc > 1500 and zcr > 0.05 and rms > 0.015:
        return "pozar_trzask", min(0.75, 0.45 + zcr * 3)
    
    # 5. Woda/wyciek
    if rms > 0.01 and rms < 0.1:
        return "woda_wyciek", min(0.65, 0.35 + rms * 2)
```

### Nowe Cechy
- 🆕 **Zero Crossing Rate** (ZCR) - szybkość zmian w sygnale
- 🆕 **Spectral Centroid** (SC) - gdzie w spektrum są dźwięki
- 🆕 **Dynamiczne Wagi** - confidence = base + parametr * waga
- 🆕 **Hybrid Mode** - AI + fallback współpracują

### Parametry
```python
MIN_CONFIDENCE = 0.25  # było 0.35 - bardziej czuły
```

**Efekt:** System będzie bardziej czuły na słabe dźwięki i dokładniej je klasyfikować.

## ✅ 2. Wyświetlanie Detekcji w GUI

### Format Starego Logu
```
[14:32:15] ~ Woda / wyciek        [0.45]  kurt=2.3
           ↑ Ikona i nazwa         ↑ Liczba 0-1  ↑ Moja wartość
```

### Format Nowego Logu (v1.1)
```
[14:32:15] ~ Woda / wyciek        [conf=45%] RMS=-15.2dB  Kurt=2.3  ZCR=0.045  SC=1200Hz
                                  ↑ Procenty ↑ dB       ↑ Kurtosis ↑ ZCR     ↑ Hz
```

### Co Się Zmienia?
1. **confidence** - teraz wyświetlany w **procentach** (45% zamiast 0.45)
2. **RMS** - zmieniony na **decybele** (dB) zamiast wartości raw
3. **Kurt** - zawsze pokazywany (miara "ostości")
4. **ZCR** - nowe (szybkość zmian amplitudy)
5. **SC** - nowe (gdzie w spektrum - Hz)

### Kod Zmian
```python
def _on_detection(self, cat, conf, feats, all_scores):
    # PRZED:
    self._log(f"~ {label:<24} [{conf:.2f}]  kurt={feats.get('kurtosis', 0.0):.1f}", "cat")
    
    # PO:
    rms_db = 20 * np.log10(feats.get('rms', 0.001) + 1e-9)
    zcr = feats.get('zcr', 0.0)
    sc = feats.get('sc', 0.0)
    msg = (f"{icon} {label:<24} [conf={conf:.2%}] "
           f"RMS={rms_db:.1f}dB  Kurt={feats.get('kurtosis', 0.0):.1f}  "
           f"ZCR={zcr:.3f}  SC={sc:.0f}Hz")
    self._log(msg, "cat" if conf > 0.6 else "warn")
```

**Efekt:** Każda detekcja pokazuje 5 dodatkowych informacji - dokładnie vidać co się stało.
